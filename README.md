# スルスル営業マン

**遊ぶ:** https://hassy0511.github.io/sample-ad-man/

広告代理店の営業マン「滑川（なめりかわ）」が、社内の「ちょっといい？」をスルッとかわしながらオフィスを駆け抜ける 3D アクションゲームです。Three.js で描いたジオラマ風のオフィスを、斜め上から見下ろして遊びます。

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | `W` `A` `S` `D` ／ 矢印キー | 画面左側をドラッグ |
| ダッシュ（回避） | `Space`（`Shift` でも可） | 右下の「ダッシュ」ボタン |
| 電話中のふり | `E`（`Q` でも可） | 右下の「電話」ボタン |
| アイテムを使う | `R`（`F` でも可） | 右下の「アイテム」ボタン |
| 会話を進める | `Enter` ／ `Space` | 会話欄をタップ |
| 一時停止 | `Esc` ／ `P` | 右上の「Ⅱ」 |

電話中のふりをすると、3.5 秒ほど先輩・課長・新人・同期・幹事が話しかけてきません（経理の鬼と社長には効きません。1ステージにつき2回まで）。床に落ちている缶コーヒーを拾うと、6 秒間足が速くなります。

ダッシュ中は一瞬だけ無敵になり、社員の手をすり抜けられます（「スルッ！」）。捕まると会話が始まり、そのぶん時計が進みます。締切までにゴールへ着けないと時間切れです。

**第7章 師走**（12月28日、仕事納めの一日）

| | 時間帯 | 業務 | 締切 | ゴール |
| --- | --- | --- | --- | --- |
| STAGE 19 | 朝 8:30 | 年内最後の入稿を届けろ（8:50 に締切が 9:45 へ前倒しになる） | 10:00 | バイク便（通用口） |
| STAGE 20 | 昼 13:00 | ロッカーを空にしろ（ロッカー室で私物を回収してから搬出口へ） | 14:00 | 搬出口（回収車） |
| STAGE 21 | 夜 20:00 | 二次会から逃げ切れ（捕まるとカラオケへ連行される） | 21:00 | 店の出口 |

**行列（第7章）** 肩に手を置いてつながった人の列が、フロアを歩き回ります。ルールは3つ。① 列のどの体に触れても捕まる。② ダッシュ中ならくぐれる（ダッシュ1回につき「スルッ！」1回）。③ 追ってくる人を列にぶつけると、その人も14秒間列に並ぶ（そのぶん列は長くなる）。列の性格は足元の輪の色で分かります。オレンジ＝触れると人数ぶん名刺交換（電話中なら会釈して通してくれる。ご一行どうしが出会うとお辞儀合戦で止まる）、緑＝横か後ろから入ると最後尾にまぎれこめて誰にも見つからない（ダッシュで降りる。先頭に正面からぶつかると掃除を頼まれる）、赤＝追ってきて、捕まると最後尾に組み込まれて奥のカラオケへ連行（時計が2倍速。ダッシュ連打でふりほどく）。先頭の頭上には人数（×5 など）が出ます。

**第8章 辞令は突然に**（4月1日、異動の日。異動先は同じビルの5階）

| | 時間帯 | 業務 | 締切 | ゴール |
| --- | --- | --- | --- | --- |
| STAGE 22 | 朝 8:30 | 段ボールを新しい席へ（台車が足あとをたどってついてくる） | 9:30 | 特命プロジェクト室 |
| STAGE 23 | 昼 13:00 | 後任に引き継げ（引き継ぎポイント3か所を後任に踏ませてから部長席へ） | 14:00 | 部長席 |
| STAGE 24 | 夜 18:00 | 自分の送別会に遅れるな（近くを歩くと同僚が足あとを追ってくる） | 19:00 | エレベーター（B1 居酒屋へ） |

**足あと（第8章）** 自分の歩いた道すじが床に足あととして残り、何かがそれを1歩ずつ同じ順番でたどってきます（角を近道したり壁を抜けたりはしない）。ダッシュ中に通った区間には足あとが付きません。朝は引っ越し業者の台車が2.4m後ろをついてきて、後ろから追ってくる人をはね飛ばしてくれます（来た道を引き返すと自分がひかれて1分ロス）。昼は後任の淀川さんが2m後ろを歩き、★の引き継ぎポイントを踏むと引き継ぎ完了。淀川さんは捕まらない代わりに、近くを通った人に律儀にあいさつしてしまい、あいさつされた人はあなたに気づいて追ってきます（電話中・傘の間は会釈だけ）。このステージでは、ダッシュで横をすり抜けた先輩には気づかれませんが、後から来る淀川さんがあいさつしてしまいます。人事の深川さんのそばを通ると、淀川さんは5秒間オリエンテーションを受けて止まります。夜は近くを歩いて通った同僚が足あとを嗅ぎつけて追ってきて、人数が増えるほど速くなります。ダッシュで足あとを途切れさせると見失い、電話中はその場で止まり、傘を開くと全員が見失います。

クリアすると「業務報告書」にハンコが押され、残り時間に応じてスルー力（S〜C）が付きます。

**味方：エース新人（早瀬くん）** 各ステージのどこかに1人います。話しかけると仲間になって後ろをついてきて、捕まりそうになった瞬間に一度だけ「先輩は今忙しいので！僕が伺います！」と身代わりになってくれます。同行者（台車・淀川さん）がいるステージでは、そのさらに後ろの足あとを歩きます。

タイトル画面の「社員名簿を開く」から、出会った人の図鑑と、それぞれに捕まった回数・かわした回数を見られます（記録はブラウザに保存）。

## 起動方法

ビルドは不要です。ES Modules と import map を使っているので、静的ファイルサーバー経由で `index.html` を開いてください（`file://` では動きません）。

```sh
python3 -m http.server 8000
# または
npx serve .
```

ブラウザで <http://localhost:8000> を開きます。Three.js（r186）は jsDelivr から、フォント（Dela Gothic One / M PLUS Rounded 1c）は Google Fonts から読み込みます。

## スマホでアプリのように遊ぶ（ホーム画面に追加）

PWA に対応しています。HTTPS で公開したページをスマホで開き、ホーム画面に追加すると、アイコンから全画面で起動できます。一度開けばオフラインでも遊べます。

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: タイトル画面の「ホーム画面に追加」ボタン、またはメニュー →「アプリをインストール」

公開には GitHub Pages が手軽です。リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` と `/(root)` にして保存すると、`https://<ユーザー名>.github.io/sample-ad-man/` で公開されます。

```
  suitcase.js     キャリーケース（床の種類で鳴る音・音の輪・発車メロディ）
  belts.js        動く歩道（乗っている人を運ぶ・踏み板の模様を流す）
  conga.js        行列（先頭の通った跡をたどるメンバー・足元の輪・人数バッジ・巻き込み）
  trail.js        足あと（主人公の道すじの記録・床の足あと）と、それをたどる同行者（台車・後任）
  pwa.js          ホーム画面への追加と Service Worker の登録
manifest.webmanifest  アプリ名・アイコン・全画面表示の設定
sw.js             オフライン用のキャッシュ
icons/            アプリアイコン
```

地図は `src/levels.js` の文字列を書き換えるだけで編集できます（記号の意味はファイル冒頭に記載）。

## 動作環境

WebGL2 が動く最近のブラウザ（Chrome / Edge / Safari / Firefox）。重い環境では自動的に後処理と解像度を下げます。
