# スルスル営業マン

広告代理店の営業マン「滑川（なめりかわ）」が、社内の「ちょっといい？」をスルッとかわしながらオフィスを駆け抜ける 3D アクションゲームです。Three.js で描いたジオラマ風のオフィスを、斜め上から見下ろして遊びます。

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | `W` `A` `S` `D` ／ 矢印キー | 画面左側をドラッグ |
| ダッシュ（回避） | `Space`（`Shift` でも可） | 右下の「ダッシュ」ボタン |
| 会話を進める | `Enter` ／ `Space` | 会話欄をタップ |
| 一時停止 | `Esc` ／ `P` | 右上の「Ⅱ」 |

ダッシュ中は一瞬だけ無敵になり、社員の手をすり抜けられます（「スルッ！」）。捕まると会話が始まり、そのぶん時計が進みます。締切までにゴールへ着けないと時間切れです。

## ステージ

| | 時間帯 | 業務 | 締切 | ゴール |
| --- | --- | --- | --- | --- |
| STAGE 1 | 朝 9:00 | 部長に企画書を届けろ | 10:30 | 部長席 |
| STAGE 2 | 昼 12:00 | ランチに抜け出せ（残り時間＝ランチの時間） | 13:00 | エレベーター |
| STAGE 3 | 夕方 18:00 | 定時で帰れ（推しのライブに間に合え） | 19:00 | 出口 |

クリアすると「業務報告書」にハンコが押され、残り時間に応じてスルー力（S〜C）が付きます。

## 社内の要注意人物

| 人物 | 動き | 捕まると |
| --- | --- | --- |
| ちょっといい先輩（佐藤先輩） | 近くを通ると気づいて追ってくる | 「5分だけ」→ 15分ロス |
| 経理の鬼（細田さん）★最強 | 赤い視界で巡回。見つかると猛ダッシュ、近くにいると足がすくむ | 細かい指摘 → 20分ロス＋書類2束 |
| 書類おじさん（山本部長代理） | 遠くから書類を投げてくる（赤い円が落下地点） | 当たると頭に書類が積もって遅くなる |
| MTG入れたがり課長（黒木課長） | 黄色い視界で巡回 | 「30分だけMTG」→ 30分ロス |
| 質問魔の新人（若葉くん） | ついてきて「せんぱ〜い！」と叫び、周りを呼び寄せる | ダッシュで振り切ると転ぶ |
| 飲み会幹事（宴田さん） | 出口の前で通せんぼ | 「今日来るよね？」→ 20分ロス |

頭に積もった書類はシュレッダーで処分できます。

## 起動方法

ビルドは不要です。ES Modules と import map を使っているので、静的ファイルサーバー経由で `index.html` を開いてください（`file://` では動きません）。

```sh
python3 -m http.server 8000
# または
npx serve .
```

ブラウザで <http://localhost:8000> を開きます。Three.js（r186）は jsDelivr から、フォント（Dela Gothic One / M PLUS Rounded 1c）は Google Fonts から読み込みます。

## スマホでアプリのように遊ぶ（ホーム画面に追加）

PWA に対応しています。HTTPS で公開したページをスマホで開き、ホーム画面に追加すると、アイコンから全画面で起動できます。一度開けばオフラインでも遊べます。

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: タイトル画面の「ホーム画面に追加」ボタン、またはメニュー →「アプリをインストール」

公開には GitHub Pages が手軽です。リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` と `/(root)` にして保存すると、`https://<ユーザー名>.github.io/sample-ad-man/` で公開されます。

## ファイル構成

```
index.html        画面の骨組み（タイトル・説明・HUD・会話・報告書）
style.css         付箋・ハンコ・報告書をモチーフにした UI
src/
  main.js         ゲーム進行（状態遷移・カメラ・会話・ゴール演出）
  levels.js       ステージの地図（1文字＝1タイル）と時間設定
  cast.js         登場人物の見た目・強さ・セリフ
  world.js        オフィスの組み立て（家具を頂点カラーで結合して描画を軽くする）
  characters.js   ローポリキャラのモデルとアニメーション、顔アイコンの生成
  enemies.js      6種類の敵の行動
  player.js       主人公の移動・ダッシュ・頭上の書類
  nav.js          当たり判定・視線・経路探索
  effects.js      パーティクル・残像・視界コーン
  textures.js     床・モニター画面・ポスターなどを Canvas で生成
  post.js         ブルーム＋ティルトシフト（ジオラマ風）の後処理
  audio.js        Web Audio で合成する効果音と BGM
  ui.js           DOM の HUD・吹き出し・画面
  input.js        キーボードとバーチャルスティック
  pwa.js          ホーム画面への追加と Service Worker の登録
manifest.webmanifest  アプリ名・アイコン・全画面表示の設定
sw.js             オフライン用のキャッシュ
icons/            アプリアイコン
```

地図は `src/levels.js` の文字列を書き換えるだけで編集できます（記号の意味はファイル冒頭に記載）。

## 動作環境

WebGL2 が動く最近のブラウザ（Chrome / Edge / Safari / Firefox）。重い環境では自動的に後処理と解像度を下げます。
